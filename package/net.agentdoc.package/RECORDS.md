# The records this agent must leave

This is the contract. The agent leaves the following behind, on
every run.

- the check of each job: how many stories, the covered list's size, the sponsors read, every link with what it answered, the marked links and their stories, every problem, whether the list passed, and in a watch whether it was quiet and how many page-change stories were not matched against the covered list — at `*/check.json`

An agent that leaves less than this does not do this job,
whatever else it does well.
